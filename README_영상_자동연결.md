# Intern Shadowing v45 — 영상 자동 연결

1. 앱에서 **영상 보관함**을 누릅니다.
2. **영상 1~7 자동 연결 (여러 파일 선택)** 버튼을 누릅니다.
3. 휴대폰의 내 파일에서 MP4 영상들을 선택합니다.
4. 앱이 영상의 실제 재생 길이를 검사해 Part 1~7에 자동 배정합니다.
5. 영상 길이가 맞지 않거나 이미 영상이 저장된 Part는 바로 덮어쓰지 않고 **직접 확인**하도록 표시합니다.

원본 영상 재생 길이 (초 단위로 식별):
- Part 1: 01:13:46.88
- Part 2: 01:13:43.70
- Part 3: 01:07:29.75
- Part 4: 00:59:07.03
- Part 5: 01:30:17.35
- Part 6: 00:57:36.87
- Part 7: 01:26:38.62

**중요:** 브라우저 보안상 휴대폰 폴더의 동영상에 자동 접근할 수 없습니다. 사용자가 한 번 파일을 선택해야 합니다. 앱 내부 보관함은 기기별 IndexedDB에 저장되며, 학습 기록 Google 동기화와 별개입니다.

서로 다른 인코딩이나 편집본은 실제 길이가 다를 수 있으므로 확인 대상으로 표시됩니다. 기존 영상을 자동으로 삭제하거나 교체하지 않습니다.
