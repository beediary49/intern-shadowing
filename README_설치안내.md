## Intern Shadowing v15

- 동일 영어 문장 중복 숨김 (항상 ON)
- “Yeah.”, “Uh.”, “Hmm.”, “Oh.”, “Okay.” 등 단독 감탄사·짧은 맞장구 자동 제외
- “Thank you.”, “I know.”, “Fire away.” 등 의미 있는 짧은 문장은 유지
- 7개 파트의 자막 시간과 영상 데이터는 수정하지 않음
- 영상 보관함과 기기 내 저장, 고정 영상 화면 유지

### 적용
1. ZIP 파일을 압축 해제합니다.
2. GitHub 저장소 beediary49/intern-shadowing의 **Add file → Upload files**에서 같은 경로의 파일을 덮어씁니다.
3. **Commit changes** 후 GitHub Pages 게시 완료를 확인합니다.
4. 앱에서 제목 아래 `v15`를 확인합니다. 캐시가 남으면 새로고침 또는 앱 재실행하세요.

참고: 삭제가 아니라 **학습 목록에서 필터링**하므로 영상과 원본 자막 파일은 유지됩니다.
