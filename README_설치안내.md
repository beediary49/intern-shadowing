# Intern Shadowing v38 — 자동 목록·이동 메모창

기존 v37 Google 로그인·학습 기록 동기화와 영상 기능을 유지하면서 UI를 개선했습니다.

- **더 보기 버튼 삭제:** 목록 하단으로 스크롤하면 자동으로 다음 120개 문장을 표시합니다. 현재 문장 자동 따라가기도 유지됩니다.
- **메모 창 이동:** 제목 「문장 메모」 영역을 잡아 드래그합니다. 스마트폰 폭(850px 이하)은 세로 방향만, PC는 가로와 세로 모두 이동할 수 있습니다. 메모 입력/완료/닫기는 기존과 동일합니다.
- Google 로그인, Firebase 설정, 영상 보관함, 구간 반복 및 학습 데이터는 초기화하지 않습니다.
