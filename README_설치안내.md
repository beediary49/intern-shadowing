# Intern Shadowing v21 – Part 1 재생 위치 및 다음 Part 자동 진행

- Part 1의 26:29 구간부터 마지막 구간까지 SRT 구간 시간 순서를 재확인했습니다.
- 27분대 두 문장이 합쳐진 구간을 분리하고 같은 긴 문장이 2회 목록에 표시되는 문제를 정리했습니다.
- 문장 클릭 시 로컬 MP4의 `seeked` 완료를 기다려 재생하도록 수정했습니다. 이전 영상 끝 위치에서 재생되거나 목록이 갑자기 끝으로 점프하는 상황을 방지합니다.
- **구간 반복 OFF**: 각 Part의 마지막 학습 문장이 끝나면 자동으로 다음 Part로 이동하여 저장된 MP4를 재생합니다. Part 7 종료 시 정지합니다.
- **구간 반복 ON**: 현재 문장만 계속 반복하며 다음 Part로 넘어가지 않습니다.
- 기기 영상 보관함에 다음 Part의 MP4가 없으면 다음 Part로 전환하고 안내문을 표시합니다.
- 원본 SRT 자체의 오인식이나 영상 내 자막과의 모든 차이를 수작업 검증한 것은 아닙니다.
