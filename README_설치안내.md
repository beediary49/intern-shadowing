# Intern Shadowing PWA — 영상 고정 및 영상 내장 저장판

## 업데이트
1. ZIP 압축을 풉니다.
2. GitHub 저장소 https://github.com/beediary49/intern-shadowing 에서 Add file > Upload files를 선택합니다.
3. 폴더와 파일 전체를 업로드해 기존 파일을 교체하고 Commit changes를 누릅니다.
4. 앱 주소 https://beediary49.github.io/intern-shadowing/ 를 실행합니다. 기존 PWA는 종료 후 다시 실행하거나 새로고침해야 최신 캐시를 받을 수 있습니다.

## 변경점
- 위쪽에는 영상만 고정, 아래쪽은 문장 목록만 스크롤합니다.
- 자막은 자동 묶음 처리해 각 반복 문구를 하나의 목록 항목으로 표시합니다. 원본 자동 자막에 오류가 있는 2~7편 일부 구간은 문장 경계와 인식 오류를 추가 수동 교정해야 합니다.
- 이전의 '자막 그대로' / '반복 문장 숨기기' 전환 버튼을 제거했습니다.
- 영상 보관함에서 Part 1~7을 하나씩 저장하면 영상 데이터가 현재 기기의 IndexedDB에 보관됩니다. 별도의 파일 다시 선택 없이 실행할 수 있습니다.
- **영상은 GitHub 저장소로 업로드되지 않습니다.** 기기별로 한 번씩 등록해야 합니다.

## 저장 공간 주의
- 전체 영상은 약 775MB입니다. 브라우저와 휴대폰에서 제공하는 저장 할당량에 따라 모두 저장되지 않을 수 있습니다.
- 앱 삭제, 브라우저 데이터 삭제, 저장 공간 자동 정리 등으로 영상이 지워질 수 있습니다. '저장 유지 요청'을 눌러 영구 저장을 요청할 수 있지만 보장되지는 않습니다.
- 한 번에 7개를 복사하지 않고 Part별로 등록하도록 하여 모바일 대용량 업로드 문제를 피했습니다.
- 인터넷 연결이 없는 상태에서도 PWA 캐시가 유지되고 영상이 IndexedDB에 있다면 재생됩니다.
