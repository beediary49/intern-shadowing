# Intern Shadowing PWA · 7편

## 포함된 기능
- Part 1~7 SRT의 모든 자막 구간과 실제 타임스탬프 보존
- ‘자막 그대로’ / ‘중복 정리’ / 검색 / 즐겨찾기 / 학습 완료 / 개인 메모
- 각 Part에 다운로드된 MP4 등 로컬 영상 파일 선택, 자막 시점 이동, 속도 조절, 선택 구간 반복
- 온라인 YouTube 연결: Part 1 링크는 제공된 URL 사용, 나머지는 사용자 등록
- 아이콘: 사용자가 보내준 이미지

## 설치
1. 이 ZIP 내용을 **그대로** 압축 해제합니다.
2. `index.html`, `manifest.webmanifest`, `sw.js`, `data`, `icons`가 같은 웹사이트 경로에 있어야 합니다.
3. GitHub Pages 또는 Netlify 등 HTTPS 정적 웹호스팅에 업로드합니다.
4. Chrome/Edge에서 주소를 열고 ‘앱 설치’ 또는 ‘홈 화면에 추가’를 선택합니다.
5. **처음 온라인에서 모든 파일이 캐시된 이후** 오프라인으로 앱/자막을 이용할 수 있습니다.

## 노트북에서 로컬 테스트
압축을 푼 폴더에서 `python -m http.server 8000`을 실행한 후 http://localhost:8000 을 열면 됩니다. `file://`로 index.html을 직접 열면 JSON 로딩 및 PWA 설치가 제한됩니다.

## 영상 연결
- 각 Part를 선택하고 **다운로드한 영상 선택**에서 해당 영상 파일을 고르세요. 파일은 서버로 업로드되지 않습니다.
- 브라우저의 보안 정책상 앱을 다시 열면 영상 파일을 다시 골라야 합니다. 영상 파일 자체는 PWA 캐시에 저장하지 않습니다.
- 영상과 SRT는 같은 원본 영상이어야 시간이 맞습니다.
- Part 2~7 YouTube 링크는 사용자가 아직 제공하지 않아 공란입니다.
- 구간 종료 시간은 SRT 자막 타임스탬프를 따르므로 실제 발화 끝과 다를 수 있습니다.

## 주의
웹사이트 업로드 시 포함된 SRT 자막이 공개될 수 있습니다. 저작권 및 공개 범위를 확인하세요. 학습 완료/메모는 기기별로 저장하며 동기화되지 않습니다.


## 7개 MP4 영상 연결 (새 기능)
- 앱의 **📁 영상 7개 한꺼번에 선택**을 누르고 영상 7개를 동시에 선택합니다.
- MP4 파일명의 `#1`~`#7` 번호를 사용해 자동으로 각 Part에 연결합니다.
- 각 파트를 바꿔도 현재 실행하는 동안 연결이 유지됩니다.
- 보안상 앱을 완전히 종료하거나 새로 고침하면 다시 선택해야 합니다. MP4 파일은 웹 호스팅에 업로드하지 않습니다.
- 영상 파일은 7개 합계 약 775MB이며 앱 ZIP에는 포함되지 않습니다. 스마트폰에도 동일한 MP4를 복사해 둬야 완전 오프라인 재생할 수 있습니다.
- 자막과 MP4의 끝 시간이 1~3초 차이 나는 구간이 있어서 재생 구간은 영상 길이 내로 제한합니다.

## 휴대폰 파일명이 바뀌는 문제 해결 (2026-11-14)
- 앱에서 **여러 영상 선택**을 누르면 파일명 대신 영상별 Part 1~7을 직접 고르는 화면이 표시됩니다.
- 갤럭시 파일 선택창에서 한 번에 한 개만 선택될 경우 **+ 파일 더 선택**을 반복해 7개를 추가할 수 있습니다.
- 각 파일의 Part 번호를 선택한 후 **선택한 영상 연결**을 누르세요.
- 잘못 고른 파일은 **현재 영상 선택**으로 해당 Part를 교체할 수 있습니다.
- 용량이 0바이트인 MP4는 재생할 수 없으므로 휴대폰에서 정상 다운로드해야 합니다.
- 기존 GitHub Pages 저장소에 이 ZIP 안의 파일을 다시 업로드하여 덮어쓴 뒤 Commit changes를 클릭하세요. 이전에 설치한 앱은 업데이트가 적용되도록 종료 후 다시 실행하세요.
