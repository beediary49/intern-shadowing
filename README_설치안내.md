# Intern Shadowing v17 — 자동 문장 따라가기 / PC 영상 왼쪽

- PC에서는 왼쪽이 영상, 오른쪽이 영어 문장 목록입니다.
- 재생 위치가 다음 표현에 진입하면 선택한 문장 강조와 목록 스크롤이 자동으로 따라갑니다.
- 문장을 직접 클릭해도 해당 문장이 목록 중앙에 오도록 이동합니다.
- 구간 반복 버튼이 켜진 상태에서는 현재 문장만 반복하므로 다음 문장으로 자동 진행하지 않습니다. **연속으로 다음 문장으로 넘어가려면 ‘구간 반복’을 눌러 끄세요.**
- 모바일은 기존처럼 영상 위/문장 아래 배치를 유지합니다.
- 로컬 MP4에서 문장 시간 추적을 지원합니다. 유튜브 임베드 영상은 브라우저 제약으로 동일한 자동 시간 추적이 되지 않습니다.
- GitHub Pages 업데이트: ZIP을 압축 풀어 전부 업로드하고 Commit changes 합니다. 기존 앱 데이터는 유지됩니다.
