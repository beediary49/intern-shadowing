# Intern Shadowing v20 — 구간 반복 기본 OFF

- **↻ 구간 반복: OFF (기본)**: MP4가 끊기지 않고 다음 문장으로 계속 진행합니다. 현재 문장 강조와 스크롤도 영상 시간을 따라갑니다.
- **↻ 구간 반복: ON**: 현재 선택한 문장의 시작~종료 구간만 무한 반복합니다. 다른 문장으로 넘어가지 않습니다.
- 버튼을 다시 누르면 OFF로 바뀌며 영상은 다음 문장으로 자연스럽게 계속 진행합니다.
- 기존 PC 좌측 영상·우측 문장 화면과 모바일 상하 배치는 유지합니다.
