# Intern Shadowing v31 — 휴대폰 Part 자동 전환 개선

- PC의 왼쪽 영상·오른쪽 문장 구성과 기존 학습 기능을 유지했습니다.
- Part 1~6은 **마지막 학습 문장이 끝나는 시점**에 다음 Part로 이동합니다.
- Part 7 마지막 문장에서는 재생을 종료합니다.
- 구간 반복 ON이면 다음 Part로 이동하지 않고 현재 문장을 반복합니다. 기본값 OFF입니다.
- 모바일에서 `timeupdate` 감지가 느려지거나 영상 종료 이벤트가 먼저 오는 문제를 대비해 종료 시점 확인을 보강했습니다.
- 새 Part로 이동한 뒤 휴대폰 브라우저가 자동 재생을 제한하면 영상에 **▶ Part N 재생** 버튼이 나타납니다. 버튼을 한 번 눌러 진행할 수 있습니다.
- 다음 Part 동영상이 해당 휴대폰 **영상 보관함**에 있어야 합니다. 노트북과 휴대폰은 각각 별도로 영상을 저장해야 합니다.

## 검증 한계
자바스크립트 구문·파일 구조를 검사했습니다. 실제 갤럭시 Chrome/삼성인터넷의 모든 자동 재생 정책을 실기기 검증한 것은 아닙니다. 모바일 정책상 자동 재생은 제한될 수 있으며 그런 경우 수동 재생 버튼을 제공합니다.
