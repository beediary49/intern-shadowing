# Intern Shadowing v44 — 온라인 영상 연결 준비판

## 작동 원리
기기에 저장한 Part별 MP4가 있으면 먼저 재생합니다. 기기에 없으면 `video-sources.js`에 등록한 HTTPS MP4 주소에서 영상을 재생합니다. 인터넷이 없을 때 온라인 스트리밍은 불가능합니다. 구간 반복과 시간 이동은 서버가 HTTP Range를 지원해야 안정적입니다.

## 온라인 파일 등록
1. 배포 권한이 있는 MP4를 별도 영상 호스팅 서비스에 업로드합니다.
2. 재생 가능한 **HTTPS 직접 MP4 URL**을 발급받습니다. CORS 설정 및 Range 요청이 가능해야 합니다.
3. `video-sources.js`의 Part 1~7 빈 문자열을 해당 URL로 교체한 후 GitHub Pages에 업로드합니다.
4. 각 Part를 선택하여 실제 영상 재생·탐색·구간 반복을 시험하세요.

### 주의
- 이번 ZIP에는 원본 MP4가 포함되어 있지 않으며 원격 업로드도 수행하지 않았습니다.
- GitHub Pages는 원본 MP4 7개(약 770MB)를 그대로 올리기에 적합하지 않습니다.
- 영화·유튜브 영상의 재배포는 권리자의 허락이 필요할 수 있습니다.
- 기존 Firebase Google 로그인, 메모, 학습 기록은 그대로 유지합니다.
- GitHub 공개 저장소에 비밀번호 또는 개인 다운로드 토큰을 넣지 마세요.
